# Titanic Survival Prediction

A machine-learning classification project exploring passenger survival in the Titanic dataset.

## Main notebook

`titanic_ds_ML xgboost.ipynb` contains the main analysis workflow:

- Inspect the dataset and identify missing values.
- Clean and prepare features for modelling.
- Engineer family-size information.
- Train and compare Logistic Regression and XGBoost classifiers.
- Evaluate model performance.

## Model results

The project experiments reached approximately:

| Model | Accuracy |
|---|---:|
| Logistic Regression | 0.78 |
| XGBoost | 0.81 |

Results depend on the notebook's preprocessing and train/test split.

## Repository contents

- `titanic_ds_ML xgboost.ipynb` — primary notebook.
- `untitled1.py` — additional Python script.
- Other root-level items are retained from earlier experiments and are not required to run the main Titanic notebook.
